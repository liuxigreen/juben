# 第十八章 锐咖啡

陈锐来的时候没带人。

他一个人，穿着一件深蓝色的polo衫，手腕上的表还是那块——但表带换过了，从金属换成了皮的。

他坐到吧台前，把一个牛皮纸信封放在台面上。

"意式浓缩。"他说。

苏念做好端过去。陈锐喝了一口，放下。杯子在台面上发出一声轻响。

他把信封推到苏念面前。

"什么？"苏念问。

"收购终止协议。"陈锐的声音很平。"公司批了。你的店不用卖了。"

苏念没碰信封。她看着陈锐的脸——他的下颌线条比上次松弛了一点，没有在磨牙。

"为什么？"苏念问。

陈锐喝了一口咖啡。他的手指在杯壁上画了一个圈，像是在做一个决定。

"你知道我以前是做什么的吗？"他问。

苏念摇头。

陈锐从口袋里拿出手机，翻到一张照片。照片里是一家很小的咖啡店——比念想还小，只有四张桌子。招牌上写着两个字："锐咖啡"。

"这是我开的。"陈锐说。"十年前。在城南的一条小巷子里。"

苏念看着那张照片。店门口有一棵桂花树，树下放着一张折叠椅。

"生意好吗？"苏念问。

"不好。"陈锐说。"亏了两年。第三年，有人来收购。出价很高。我——"

他停了。他的手指在手机屏幕上停了一下，照片放大了——门口的折叠椅上，坐着一个年轻女人。

"这是我老婆。"陈锐说。"当时还是女朋友。她在这张椅子上等我关店，等到睡着了。"

苏念看着那个女人。她侧着头，靠在椅背上，眼睛闭着。阳光从桂花树的缝隙里漏下来，落在她的脸上。

"我卖了。"陈锐说。"第三年年底，我卖了。用那笔钱，我买了房子，结了婚，进了现在这家公司。"

他的声音没有起伏，但他的手指在手机边缘掐出了痕迹。

"后来呢？"苏念问。

"后来——"陈锐把手机收起来，"公司让我去收购别人的小店。一家一家收。我收了十几家。每次签完合同，我都会去那家店坐一会儿，喝最后一杯咖啡。"

他喝了一口意式浓缩。

"然后我发现——"他的声音在发抖，"每收一家店，我就忘掉一点自己开'锐咖啡'时的感觉。忘掉桂花树下的味道。忘掉老婆在折叠椅上等我的样子。忘掉——"

他停了。

"忘掉什么？"

"忘掉我为什么喜欢咖啡。"陈锐说。

苏念的指甲在吧台上敲了一下。

"所以你来收购我的店——"

"是因为我必须完成公司的任务。"陈锐说。"但每次来你这里，我都会想起来——我以前也是这样的人。守着一家小店，不想卖。"

他把信封又推了一下。

"签了吧。"他说。"公司不会再来了。我跟他们说了——这条巷子不适合开发。结构不达标，拆迁成本太高。"

苏念看着那个信封。

"你跟公司撒了谎。"

"我跟公司说了实话。"陈锐说。"这条巷子的楼确实结构不达标。但不达标的原因是——开发商当年偷工减料。我查过了。那个开发商——"

他停了。

"是谁？"

"是我现在这家公司的母公司。"陈锐说。"二十年前的事了。他们当年偷工减料，现在又来收购拆迁——就是为了销毁证据。"

苏念的手攥紧了杯子。

"你知道这些——你还帮他们收购？"

"我以前不知道。"陈锐说。"是最近才查到的。所以我辞职了。"

苏念的呼吸停了。

"你也辞职了？"

"昨天递的辞呈。"陈锐说。他的声音恢复了平时的平静，但他的眼睛里有一种苏念没见过的表情——像是卸下了一副很重的担子。

"你和顾深——同一天辞职？"

"巧合。"陈锐说。他的嘴角动了一下——不是笑，是苦笑。"不过，也许不是巧合。"

他站起来，从口袋里掏出钱包，抽出一张二十块钱，放在吧台上。

"不用找了。"

他走到门口，停下来。

"苏老板。"

"嗯。"

"你外婆的咖啡——是我喝过最好的。"陈锐的声音在发抖。"比我自己做的好。"

他走了。门关上。风铃晃了两下——风铃修好了，声音比以前清脆了一点。

苏念站在吧台后面。她看着那个牛皮纸信封，手指在信封边缘停了三秒。

她拆开信封。里面是一份文件，三页，右下角有红色的公章。但公章旁边，有人用蓝色圆珠笔写了一行字：

*"苏老板，对不起。——陈锐"*

苏念把文件折好，放进吧台的抽屉里。

她走到墙边，看着外婆的便签。便签上的字又淡了一个笔画。

她伸手摸了摸便签。纸面冰凉。

然后她看到——便签旁边，多了一张新的便签。

不是外婆的字迹。

是陈锐的字迹。

*"念想咖啡，值得留下来。"*

苏念看着那张便签。她不记得陈锐什么时候贴上去的。

但便签的边角——已经被咖啡渍浸黄了。

像是贴了很久。
