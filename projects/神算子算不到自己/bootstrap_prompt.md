# Juben 角色与世界观填充任务

你是一个专业的剧本架构师。根据以下信息，为这个故事项目生成完整的角色卡和世界观设定。

## 故事前提
乾元大陆第一算师陆九，能算天算地算尽苍生，唯独算不到自己在意的人。某日推演发现三日后自己头顶要绿——其实是他命中注定的'神女降世劫'开始：枕边人(实为上界神女转世)被天机阁追杀，被算卦盘碎裂的命格开始全面反噬。他靠'算不准自己'的反讽金手指，苟着破局。

## 意外变量（核心金手指）
算卦盘碎裂，命格反噬——他算不到自己，成了他在死局中最大的金手指

## 已有规则约束

### 因果约束（不可违反）
- 古代没有手机、互联网、外卖，不能出现任何现代通讯工具
- 女性在古代社会地位受限，女主的每一步突破都必须有合理的时代逻辑支撑
- 银两购买力要符合时代，不能'一掷千金'却毫无后果
- 古代信息传递靠驿站/信鸽，消息有延迟，不能秒传
- 朝堂规则：奏折、廷议、圣旨都有固定流程，不能随意'面圣'
- 医药水平有限，重伤不能三章痊愈
- 古代出行靠马/轿/步行，距离感要真实

### 反套路黑名单（禁止出现的情节）
- 女主穿越后随口背唐诗宋词震惊全场——古人也会写诗，没那么稀罕
- 女主用现代医学知识秒变神医——古代没有消毒液和抗生素
- 女主随口说出'民主''平等'引发朝堂震动——古人听不懂也不会当回事
- 男主是王爷/太子却天天闲着陪女主逛街——皇族有规矩有差事
- 丫鬟/侍女对主子直呼其名——古代主仆尊卑分明
- 女主在古代开奶茶店/火锅店发家致富——原材料和供应链从哪来？
- 圣旨/懿旨像微信消息一样随便发——拟旨有流程，用印有规矩
- 女主在宴席上当众跳舞/弹琴惊艳四座——古代大家闺秀抛头露面是失礼
- 穿越者用'现代思维'碾压所有人——古人的智慧不比现代人差
- 女主轻松进出皇宫如入无人之境——宫禁制度极其严格
- 系统发布任务就给奖励，不做就死——系统不是老板，不能这么霸道
- 金手指无任何代价——没有代价的能力不值得写
- 主角升级速度碾压所有人——合理解释为什么是他而不是别人
- 签到/打卡就能变强——这不是成长，这是摸鱼
- 被当众羞辱时小弟赶到下跪——反转要有铺垫，不能靠人数
- 反派死于话多，主动告诉主角关键信息——聪明的反派不会这样
- 主角每次危机都有贵人相助——巧合不能当剧情引擎
- 退婚/退学/被开除后对方后悔——被抛弃→逆袭的套路太老了
- 实力等级森严但主角一路越级挑战——那等级制度还有什么意义？
- 拍卖会/比武大会/宗门大比——这三个场景占了80%的网文字数
- 隐世老人其实是绝世高手——逢人就教功夫的老人不可信

### 核心原则
- 爽感来源：用智谋碾压，不是用外挂碾压
- 升级有代价，能力越大责任越大
- 配角不是工具人，每个人都有自己的动机
- 反派要聪明，蠢反派赢了也没成就感

## 算法卡点（每章必须遵循的节奏）
- [3s_Hook] 0-100字: 开局即冲突。第一句话必须是有人在看不起/羞辱/威胁主角，或者主角正在面对一个不可能的困境
- [15s_Retention] 300-500字: 主角亮出一张底牌（不是全部实力，只是一个信号）。让读者知道'好戏要来了'
- [Face_Slap] 600-900字: 第一次打脸。但不能太轻松——主角需要付出一定代价或动用一定资源，让读者觉得'值'
- [Escalation] 1000-1300字: 打脸引出更大的敌人/更深的危机。小爽之后必须有大坑，否则读者没有继续看的理由
- [50s_Cliffhanger] 1700-2000字: 断崖。主角刚解决一个问题，更大的威胁浮现——或者一个关键信息暴露，改变整个局面

## 设计要求

1. **角色必须有缺陷**：完美的主角没有故事。给主角一个真实的、影响剧情的弱点。
2. **反派必须有逻辑**：反派的动机不能是"天生坏"。给反派一个读者能理解（但不认同）的理由。
3. **关系必须有张力**：角色之间的关系不是静态的。标注出潜在的变化方向。
4. **信息差必须具体**：不要写"主角知道未来"，要写"主角知道某人在第X章会做某事"。
5. **符合已有的因果约束和反套路黑名单**：生成的内容不能违反上面列出的任何规则。
6. **实体锚点必须具体可拍**：每个核心抽象概念（如"经济压力"、"神秘威胁"、"职业身份"）都必须解构为一个可以在镜头前展示的物理道具/UI界面，并给出3个硬核关键词。禁止用抽象名词作为锚点。
7. **NPC必须有隐秘动机和个人目标**：每个非主角角色必须有`hidden_motivation`（不告诉主角的真实目的）和`personal_goal`（独立于主线的自身诉求）。这两个字段是NPC行为的锚点——没有它们，NPC就会退化成解说员。主角可以留空。



只输出JSON，不要输出任何其他文字。
