# 爆款结构配方（Hit Formula）

> 数据来源：4497 条真实在投短剧（抖音/红果系，7 语种发行）逐条分析语料。
> 用法：Architect 选题后按本配方排布单集结构；Scribe 按台词规范写正文；
> Guardian/rhythm 按本配方的数值校验。机器可读版见 `juben/data/corpus_stats.json`。

## 1. 单集结构（90 秒 / 500-900 字台词本体）

| 时间 | 字数 | 节拍 | 要求 |
|---|---|---|---|
| 0-3s | 0-50 | 钩子画面 | 感官冲击直给，禁止背景铺垫 |
| 12-18s | 80-160 | 第一次冲突升级 | 立场交锋开始，15 秒内必有新信息 |
| 25-35s | 170-300 | 信息差炸弹 + 小反转 | 主钩子必须被观众看懂（语料钩子出现中位 25s） |
| 40-50s | 300-420 | 打脸前蓄力 | 施辱者把赌注/羞辱抬到最高 |
| 55-65s | 430-560 | 爆点 | 打脸/揭露/物理冲击，当众翻转 |
| 70-78s | 560-680 | 爽点兑现 | 旁观者反应特写（惊呼/下跪/改口） |
| 78-85s | 680-780 | 新变量 | 第二次反转或更大敌人现身 |
| 85-90s | 780-900 | 断崖 | 未回答的问题/突发事件，卡在最后一口气 |

## 2. 反转预算

- 每集 ≥2 次反转（语料中位 3 次/部；100% 的剧至少 1 次；23% 达 4 次以上）。
- 同一反转方式不得连用 2 集（打脸方式轮换：身份揭露 → 实力碾压 → 证据反转 → 局中局）。

## 3. 开场钩子配给（语料实证占比）

| 主钩子 | 占比 | 执行要点 |
|---|---|---|
| 身份反差 | 34% | 被羞辱者藏着碾压性身份；画面里埋一个观众能看懂的符号 |
| 关系背叛 | 20% | 最亲的人当众捅刀（未婚妻/兄弟/家人）；背叛现场直给 |
| 情绪爆点 | 17% | 弱者被逼到绝境（救命钱/葬礼/孩子），情绪不解释直接演 |
| 时间改命 | 9% | 重生/回溯睁眼即知仇人，立刻行动不犹豫 |
| 系统异能 | 7% | 打脸瞬间系统激活，奖励可视化 |
| 补偿回报 | 2% | 当年被救的人如今百倍报恩 |
| 反转打脸 | 2% | 开场即打脸，先爽后讲理 |

## 5. 台词规范（尊重观众 = 不注水）

- 每分钟 380-460 字台词（语料开场实测中位 456 字/分钟、7.6 字/秒）。
- 单句 ≤15 字；每句要么推进信息要么拉升情绪，二者都不占的删掉。
- 一场对手戏 10-20 个回合，每回合立场/信息/情绪至少变一个。
- 单人连续 ≥3 句背景陈述 = 信息倾倒，禁止（真相挤牙膏式暴露）。
- 主角内心 OS 每集 1-3 句，放在打脸/复仇关键节拍。

## 6. 付费卡点（红果/小程序模式）

- 第 6-10 集设首个卡点 = 全剧情绪最高点 + 极致悬念（孩子身世揭开一半/身份暴露给第三方）。
- 此后每 5-10 集一个卡点；卡点前一集末尾必须断崖。

## 7. 爽点强度分级（配合 satisfaction-matrix.md）

轻视/侮辱 → 蓄力 → 身份揭露 → 碾压 → 跪地求饶，五级递进；
每集至少走完一次完整链条的 3 级；大结局走满 5 级。
